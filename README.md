# مراجعة موشن الرعب v2 — اختبار أرشيفي فقط

الفيديو الكامل يعيد رسم قصة بعثة فرانكلين السابقة بصوت Charon الأصلي المطابق للتوقيت؛ ليس حلقة يومية جديدة ولا موضوعًا جديدًا. العينة المتحركة نحو 40 ثانية مقتطعة من نفس اختبار المراجعة. لا يُسمح بنشرهما تلقائيًا أو استخدامهما لقبول الانتقال إلى المسار الجديد.

أضيفت إضاءة وظلال وخامات وحركة كاميرا اختيارية مع الحفاظ على هندسة المشاهد والسجل القديم. شعار الرعب الأصلي غير متوفر ولم يُستبدل بشعار مرسوم.

الملفات اجتازت ffprobe وفك ترميز الفيديو والصوت الكامل باستخدام ffmpeg. هذه فحوص تقنية؛ المراجعة الفنية والسمعية البشرية مطلوبة.
