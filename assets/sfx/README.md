# مؤثرات arabic-horror-stories

حزمة مؤثرات رعب غير موسيقية للمونتاج:

- `horror_reveal_hit.mp3`: كشف أو ضربة رعب افتتاحية.
- `horror_distant_footsteps.mp3`: ثلاث خطوات بعيدة على أرضية خشبية.
- `horror_abandoned_room_loop.mp3`: جو غرفة مهجورة ليلي قابل للتكرار.

يضيف مسار المونتاج المؤثرات تلقائيًا: جو الغرفة عند `0.045`، ضربة الكشف عند `0.22` بعد بداية السرد، وخطوات بعيدة عند 38% و72% من مدة الحلقة، مع limiter نهائي `-0.45 dBFS`. ملف `narration.mp3` يظل صوت السرد النظيف للفحوص، أما الفيديو النهائي فيستخدم النسخة الممزوجة. لا توجد موسيقى خلفية.
